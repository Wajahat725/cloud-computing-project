### 📋 Project Overview

This project demonstrates the end-to-end deployment of a containerized Node.js web application on AWS Free Tier infrastructure. The complete workflow includes:

1. **Building** a Node.js web application with Express
2. **Containerizing** the application using Docker
3. **Storing** the container image in Amazon ECR (Elastic Container Registry)
4. **Deploying** to Kubernetes (Minikube) on an EC2 instance
5. **Exposing** the application publicly via NodePort

The application displays dynamic information including Container ID, real-time timestamp, and a visitor counter.

### 🎯 Primary Goal Achieved

> *Understand the end-to-end workflow of containerization, container registry, and Kubernetes deployment on a single-node cluster, entirely within free tier constraints.*
